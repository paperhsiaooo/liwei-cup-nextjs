## 📋 登入頁面測試 (`/auth/login`)

### 基本功能測試

#### 1. 頁面載入

- [ ] 訪問 `http://localhost:3000/auth/login`
- [ ] 頁面正確顯示標題「力維盃 2025 登入」
- [ ] 顯示 Email 輸入框
- [ ] 顯示密碼輸入框
- [ ] 顯示登入按鈕
- [ ] 顯示「還沒有帳號？立即註冊」連結

#### 2. 表單驗證測試

**空白表單提交**

- [ ] 點擊登入按鈕（不輸入任何資料）
- [ ] ✅ 應顯示「請輸入 Email」錯誤訊息

**Email 格式驗證**

- [ ] 輸入無效 Email（如：`test`）
- [ ] 點擊其他地方（觸發 blur）
- [ ] ✅ 應顯示「請輸入有效的 Email」錯誤訊息
- [ ] 輸入有效 Email（如：`test@example.com`）
- [ ] ✅ 錯誤訊息應消失

**密碼長度驗證**

- [ ] 輸入短密碼（少於 8 字元，如：`1234567`）
- [ ] 點擊其他地方（觸發 blur）
- [ ] ✅ 應顯示「密碼至少需要 8 個字元」錯誤訊息
- [ ] 輸入 8 字元以上密碼
- [ ] ✅ 錯誤訊息應消失

#### 3. 密碼顯示/隱藏功能

- [ ] 預設密碼應為隱藏狀態（顯示 ••••）
- [ ] 點擊眼睛 icon
- [ ] ✅ 密碼應變為明文顯示
- [ ] ✅ Icon 應改變（EyeOff）
- [ ] 再次點擊眼睛 icon
- [ ] ✅ 密碼應回到隱藏狀態

#### 4. 登入流程測試（需要後端 API）

**成功登入**

- [ ] 輸入有效 Email：`test@example.com`
- [ ] 輸入有效密碼：`Password123`
- [ ] 點擊登入按鈕
- [ ] ✅ 按鈕應顯示 Loading 狀態
- [ ] ✅ 登入成功後應導向 `/settings/profile`
- [ ] 開啟開發者工具 → Application → Session Storage
- [ ] ✅ 應該有儲存 token

**失敗登入**

- [ ] 輸入錯誤的 Email 或密碼
- [ ] 點擊登入按鈕
- [ ] ✅ 應顯示錯誤訊息（由後端回傳）
- [ ] ✅ 不應導向其他頁面
- [ ] ✅ Email 應保留，密碼應清空

#### 5. 導航測試

- [ ] 點擊「立即註冊」連結
- [ ] ✅ 應導向 `/auth/signup`

#### 6. 響應式設計測試

- [ ] 手機尺寸 (< 640px) - 卡片寬度 100%
- [ ] 平板尺寸 (768px) - 卡片最大寬度 500px
- [ ] 桌面尺寸 (1920px) - 卡片最大寬度 600px，居中顯示
